## Overview
This project demonstrates an end-to-end data engineering and analytics workflow by integrating data from multiple real-world formats (CSV, JSON, and SQL) into a single, analysis-ready dataset.
The final output acts as a single source of truth for exploratory data analysis (EDA), business insights, and further modeling.

## Project Objectives
- Integrate heterogeneous data sources into one dataset
- Preserve transactional integrity using appropriate joins
- Perform business-focused exploratory data analysis
- Answer analytical and reasoning-based questions
- Simulate a real-world food delivery analytics use case
